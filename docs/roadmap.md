# 扩展方向与变更历史

本页记录项目的**候选扩展方向**（Backlog）以及**变更历史**（Changelog）。
文档随实现持续推进：每新增/调整功能，请在对应章节记录，并在 Changelog 追加一行。

## 候选扩展方向（Backlog）

按优先级（高 → 低）列出尚未实现的能力。实现时请移入 Changelog 并在本文档登记。

### 高优先级
- [ ] **WebSocket 实时推送**：当前为 1s HTTP 轮询，可改为 WebSocket 推送，降低请求量、
      提高实时性（尤其配合高频刷新或加速模式）。
- [ ] **换水 / 过滤**：新增「换水」控制（稀释氨氮/亚硝酸盐/硝酸盐）、「滤材/过滤」参数，
      让生态调控手段更完整。
- [ ] **waste（废物/生物负荷）动态化**：当前 `waste` 为只增不减的指示性存量；
      可改为随喂食增加、随细菌/过滤分解而下降的动态指标，并与氨氮产出挂钩。

### 中优先级
- [ ] **更多外部条件**：CO₂ 注入、造浪/水流、pH 调节液、盐度、喂食定时器等。
- [ ] **生态平衡更真实**：引入藻类爆发、磷酸盐/钾/铁等营养元素、昼夜光照周期。
- [ ] **更多物种**：食草鱼/食肉鱼、虾、螺、浮萍等，及物种间捕食/共生关系。
- [ ] **趋势图增强**：引入 ECharts 等图表库，支持多条序列、缩放、图例、悬浮提示。

### 低优先级 / 其他
- [ ] **多鱼缸实例**：从单例 `tank` 改为按 `tank_id` 管理多个独立鱼缸。
- [ ] **持久化 / 场景预设**：保存/加载鱼缸状态，或提供预设场景（新手缸、猛鱼缸、原生缸）。
- [ ] **配置化参数**：理想范围、反应系数、初始条件等抽到配置文件，免改代码。
- [ ] **服务化剥离**：把模拟引擎拆成独立可运行单元（或 C++ 扩展），HTTP 层调用。
- [ ] **测试**：为模型 `step()`/`health()` 添加单元测试，锁定行为。

## 变更历史（Changelog）

> 格式：`YYYY-MM-DD 类别 描述`。新条目加在列表**顶部**。

- `2024-01-01 tune` — 调整鱼类繁殖为**稍微过量繁殖**：解除“剩余食物>0.2”硬门槛
  （此前食物衰减导致永不繁殖）、放宽环境门槛（仅严重污染才抑制）、每成年鱼繁殖率
  提升到 0.25/h、容量作为软上限；并软化污染响应（鱼产氨 0.006→0.003、细菌处理
  0.02→0.03），使加鱼后种群确实增殖、污染上升更平滑。同步更新 `docs/model.md`。
- `2024-01-01 feat` — 新增**加水/鱼缸容量**：`add-water` 每次 +10L，扩容并稀释污染
  浓度；鱼承载力 `capacity` 随水量线性提升（可养更多鱼），污染源随水量稀释。
  看板新增「💧 加水」按钮与水量/容量显示。同步更新 `docs/model.md`、
  `docs/api.md`、`docs/dashboard.md`。
- `2024-01-01 feat` — 鱼类改为**年龄分层模型**：给每条鱼记录年龄，划分幼鱼/成年/老年
  三个阶段；成年鱼在环境良好时**繁殖**产幼鱼，老年鱼/超龄鱼**死亡**率升高，并结合
  污染/缺氧压力致死；状态新增 `fish_age`（幼/成/老 + 平均年龄），看板鱼卡片显示
  年龄结构。同步更新 `docs/model.md`、`docs/api.md`、`docs/dashboard.md`。
- `2024-01-01 feat` — 新增**过滤设备**开关（`filter`）：点选开启、取消关闭；
  开启后随时间过滤废物 `waste`，并小幅净化氨氮/硝酸盐。看板顶部新增
  「🧹 过滤设备」开关按钮。同步更新 `docs/model.md`、`docs/api.md`、
  `docs/dashboard.md`。
- `2024-01-01 feat` — 温度支持**恒温 / 昼夜循环两模式**：新增 `temp-mode`、
  `temp-set`、`temp-min`、`temp-max`、`day-hours`、`night-hours` 控制动作；
  昼夜模式在最低~最高温之间按昼长/夜长平滑波动；看板新增温度设置面板。
  同步更新 `docs/model.md`、`docs/api.md`、`docs/dashboard.md`。
- `2024-01-01 feat` — 喂食/加草/补菌/加鱼改为**可调节数量**：每个控件新增 −/＋
  数量步进器（1~99 份），可一次施加多份；关灯保留为开关按钮。同步更新
  `docs/dashboard.md`。
- `2024-01-01 chore` — 默认端口由 8000 改为 **10000**（10000 之后），并新增
  环境变量 `AQUARIUM_PORT` 覆盖；同步更新 README 与 docs 中的端口说明。
- 2024-01-01 `chore` —（占位）清空；实际条目随功能落地逐条在顶部追加。

### 已实现功能快照（截至文档创建）

以下为项目当前已实现的能力，作为基线记录：

- **后端**：FastAPI + Uvicorn；后台线程每 0.5s 步进模拟。
- **模拟模型**：氮循环（氨氮→亚硝酸盐→硝酸盐）、溶氧、pH、温度、
  鱼/水草/硝化细菌 5 类种群动态、生态健康度。
- **外部条件**：pause/resume、speed、feed、light、temp、add-plants、
  add-bacteria、add-fish、reset 共 9 种。
- **接口**：`GET /api/state`、`POST /api/control`、`GET /api/health`、`GET /`（看板）。
- **看板**：健康度条、5 类种群卡片、6 项水质量表、Canvas 趋势折线、
  按钮 + 滑块控制；前端每 1s 轮询，控制后即时刷新。
- **技术栈**：Python 3.12 + FastAPI；前端原生 HTML/CSS/JS。
