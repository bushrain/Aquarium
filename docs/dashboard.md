# 网页看板说明

本页说明前端网页看板（`static/`）的**页面布局、各面板功能与交互控件**。
前端为原生 HTML/CSS/JS，无框架依赖。

## 页面结构

看板为单页，从上到下依次为：

1. **页头**：标题 + 运行状态元信息（模拟时间、速度、运行/暂停）
2. **生态健康指数**：条形 + 数值
3. **种群统计**：5 张卡片
4. **水质指标**：6 张带量表的卡片
5. **历史趋势**：Canvas 折线图
6. **外部条件控制**：按钮 + 滑块
7. **页脚**：说明

## 各面板说明

### 1. 页头 (head)
- 标题「🐟 鱼缸水生态系统模拟看板」
- `meta-time`：模拟已进行小时数
- `meta-speed`：当前速度倍速
- `meta-running`：运行中/已暂停（运行=绿，暂停=黄）

### 2. 生态健康指数 (health-panel)
- 一条横向进度条，宽度 = `health`%（0~100）
- 颜色：≥75 绿、45~74 黄、<45 红
- 右侧显示 `health / 100`

### 3. 种群统计 (pop-grid)
| 卡片 | ID | 显示 |
| --- | --- | --- |
| 🐠 鱼 | `pop-fish` | `state.fish` + 年龄结构 `pop-fish-age`（幼/成/老 + 平均年龄） |
| 🌿 水草 | `pop-plants` | `state.plants` |
| 🦠 硝化细菌 | `pop-bacteria` | `state.bacteria` |
| 🍤 食物 | `pop-food` | `state.food` |
| 🧹 废物 | `pop-waste` | `state.waste`（生物负荷累积） |

### 4. 水质指标 (metric-grid)
每项显示：名称、当前值+单位、一条量表。

量表逻辑（`renderMetrics` / `colorFor`）：
- 理想范围用绿色边框半透明区带表示（`gauge-ideal`）。
- 当前值填充条按 `value / max` 显示。
- 颜色：在理想范围内绿；离开理想范围按偏离程度转黄、再转红。

| 指标 | key | 单位 | 量表上限 max |
| --- | --- | --- | --- |
| 溶解氧 | `oxygen` | mg/L | 14 |
| 氨氮 | `ammonia` | mg/L | 1.5 |
| 亚硝酸盐 | `nitrite` | mg/L | 1.5 |
| 硝酸盐 | `nitrate` | mg/L | 80 |
| 酸碱度 | `ph` | — | 9 |
| 温度 | `temp` | °C | 35 |

每个指标的理想范围取自 `state.ideal[key]`（由后端下发）。

### 5. 历史趋势 (trend-chart)
用 Canvas 手绘折线图：
- 三条序列：溶解氧（蓝）、氨氮（黄）、硝酸盐（绿）
- Y 轴固定 0~12（按当前模型量级）
- X 轴为模拟时间（小时）
- 右上角图例
- 数据来自 `state.history`（后端保留最近 120 点）

### 6. 外部条件控制 (controls + sliders)

分两部分：顶部一排**开关/全局**按钮，下方一组**可调节数量**的控件。

**顶部按钮**（通过 `POST /api/control`，见 [api.md](api.md)）：

| 按钮 | action / value |
| --- | --- |
| ⏸ 暂停 / ▶ 继续 | `pause` / `resume` |
| 💡 关灯 / 开灯 | `light`, `!state.light` |
| 🧹 过滤设备 开/关 | `filter`, `!state.filter_on` |
| 💧 加水 | `add-water`, 10 |
| ↺ 重置 | `reset` |

顶部按钮下方显示**水量信息**：`💧 当前水量 X L · 可养鱼上限 Y 条`。
点「💧 加水」每次 +10L，扩容同时稀释污染浓度，可承载更多鱼。

**可调节数量的控件**：用于「喂食 / 加草 / 补菌 / 加鱼」。每个控件带一个
**数量步进器（− / ＋）** 和一个「一次 +N 份」的确认按钮：

| 控件 | action | 每份单位 | 默认份数 | 步进范围 |
| --- | --- | --- | --- | --- |
| 🍤 喂食 | `feed` | 1 份食物 | 1 | 1~99 |
| 🌿 加草 | `add-plants` | 1 株水草 | 1 | 1~99 |
| 🦠 补菌 | `add-bacteria` | 1 单位菌群 | 1 | 1~99 |
| 🐠 加鱼 | `add-fish` | 1 条鱼 | 1 | 1~99 |

- 点击 − / ＋ 调整份数（最小 1，最大 99），确认按钮上的「N」随之更新。
- 点击「一次 +N 份」即调用 `/api/control`，`value` 为当前设定份数，
  一次施加多份。每项的份数独立记忆，互不影响。
- 关灯（光照）为开关布尔量，无份数概念，因此保留为顶部开关按钮。

**速度滑块**：

| 滑块 | action | value | 范围 |
| --- | --- | --- | --- |
| 速度 | `speed` | 0.1~10 | step 0.1 |

### 7. 温度设置面板（恒温 / 昼夜循环）

面板顶部显示**当前温度**，并提供模式切换（恒温 / 昼夜循环）：

- **恒温模式**：提供「目标温度」滑块（`temp-set`，4~35°C），
  温度缓慢收敛到设定值。
- **昼夜循环模式**：提供四个参数滑块
  - 最低温 `temp-min`（4~35°C）
  - 最高温 `temp-max`（4~35°C）
  - 昼长 `day-hours`（1~24h）
  - 夜长 `night-hours`（1~24h）
  - 在该范围内按昼夜周期平滑波动（白天升温至最高温、
    夜晚降温至最低温），前端显示当前温度随昼夜变化。
- 模式切换通过 `temp-mode`（`"constant"` / `"daynight"`）触发。

控件触发后，前端立即用 `/api/control` 的返回值刷新看板，无需等下一次轮询。

## 数据流

1. 页面加载 → `bindControls()` 绑定事件 → `refresh()` 拉取一次 → `setInterval(refresh, 1000)`。
2. `refresh()` 每隔 1s `GET /api/state`，用返回状态重绘健康度/种群/指标/元信息/趋势图。
3. 控件点击 → `POST /api/control` → 用返回快照立即 `render(...)`。
4. 服务不可用时轮询静默跳过（`fetchJSON` 抛错被 `catch` 吞掉），恢复后自动继续。

## 样式要点

- 暗色主题（背景 `#0e1726`，面板 `#182439`），CSS 变量集中管理配色。
- `metric-grid` / `pop-grid` 使用 `auto-fit, minmax(...)` 自适应列数，兼容不同屏宽。
- 指标卡片、量表、滑块均使用 CSS 变量；颜色随 `health`/水质状态动态变化。
