# 鱼缸水生态系统模拟（后台服务 + 网页看板 + 桌面前台）

一个用 **Python (FastAPI)** 实现的鱼缸水生态系统模拟后台服务，并通过 **网页看板**实时
展示水质指标、种群数量、生态健康度和历史趋势；你可以在网页上施加外部条件
（喂食、光照、温度、加草、补菌、加鱼、暂停、重置等）直接影响生态平衡。

另附 **PySide6 桌面前台**：一个无边框“鱼缸”桌面应用，实时渲染鱼群、水草、灯光、
过滤器气泡与水流动画，并按水质区分水体清澈程度。

> 上班摸鱼千千万，不如自己养条鱼。本项目献给所有想把鱼缸搬上工位的朋友：
> 老板以为你在看实时监控大盘，同事以为你在赶周报，其实你只是在看鱼——
> 而且这缸鱼不用请人代喂，放假三天也饿不死。

## 边上班，边养鱼

本项目专为“工位鱼类爱好者”设计，使用场景包括但不限于：

- **带薪养鱼**：桌面前台是无边框玻璃缸，往副屏一放，看起来就是个了不得的
  实时监控大盘；鱼游得再欢，也不耽误你保持“认真沉思”的职业表情。
- **合法摸鱼**：喂食、开灯、加水都是鼠标一点的事，单次操作约 0.5 秒，
  正好够你完成从“干活模式”到“摸鱼模式”的无感切换。
- **老板路过预警器**：生态健康指数跌破 60，往往比老板的脚步声更早提醒你：
  该回去干正事了。
- **工作与养鱼的共同点**：都得定时投喂、定期打扫，而且谁也不能保证
  “鱼/需求”不变卦。
- **死鱼与渔网**：鱼死了要捞走，锅来了要接住——这个功能能教会你的职场道理，
  比团建多。

一句话总结：本项目里的鱼是模拟的，摸鱼是真实的，升职加薪纯属虚构。

## 运行

需要 Python 3.10+，并已安装 fastapi、uvicorn、pydantic。

```bash
# 1) 安装依赖（首次）
python -m pip install -r requirements.txt

# 2) 启动后台服务
python app.py
# 或者（推荐日志更清晰）：
uvicorn app:app --host 127.0.0.1 --port 10000
```

后台模拟线程会自动启动。浏览器打开：

```
http://127.0.0.1:10000
```

即可看到网页看板。

### 后台地址

| 项目 | 地址 |
| --- | --- |
| 后台服务（网页看板入口） | `http://127.0.0.1:10000` |
| API 基址 | `http://127.0.0.1:10000/api` |
| 健康检查 | `http://127.0.0.1:10000/api/health` |

- 默认只监听本机回环 `127.0.0.1`，局域网内其他设备无法访问；如需临时开放，
  可改用 `uvicorn app:app --host 0.0.0.0 --port 10000`（接口无鉴权，勿暴露到公网）。
- 端口可用环境变量 `AQUARIUM_PORT` 覆盖（后台与桌面前台都会读取该变量），例如
  `set AQUARIUM_PORT=10001` 后，所有地址中的端口变为 `10001`。

## 桌面前台（无边框鱼缸）

```bash
# 安装桌面端依赖（首次）
python -m pip install -r desktop/requirements.txt

# 在 aquarium 目录下启动（后台未运行时会自动拉起）
python -m desktop
# 或双击 启动桌面鱼缸.bat
```

- **无边框鱼缸窗口**：整个窗口即鱼缸（圆角半透明玻璃质感），可在水域拖动移动、
  边缘缩放、双击最大化；右上角有最小化/关闭按钮。
- **动画**：鱼群按后台数量与年龄结构游动（点击水面会惊吓鱼群）、水草摆动、
  顶灯光柱、过滤器出水口冒泡与水流速线、食物下沉、水面波浪。
- **死鱼与渔网**：后台鱼数减少即判定死鱼——翻白肚漂上水面随水流漂移；
  点击“🥅 渔网”进入捞鱼模式（光标变渔网），点击或按住拖动即可把死鱼捞走扔掉。
  （职场隐喻过于真实，此处不予展开。）
- **喂食模式**：点击“🍚 喂食”后光标变为鱼食，在水面内单击即在指针处掉落一小撮
  鱼食（同时向后台发送 feed）；右键随时退出工具模式。一键投喂，成本为零，
  是本项目里最接近“带薪撸猫”的功能。
- **水质清澈度**：由氨氮/亚硝酸盐/硝酸盐/有机废物计算——清澈时水体青蓝透亮，
  富营养化时逐渐发绿，严重污染时褐浊并出现漂浮颗粒与雾团。
- **控制**：底部悬浮栏（🍚 喂食 / 🌿 水草 / 🐟 加鱼 / 💧 加水 / 🦠 细菌 /
  💡 灯光 / 🌀 过滤），“⚙ 更多”里还有暂停/速度/恒温或昼夜温度/重置。
- **后台连接**：桌面前台连接同一后台地址 `http://127.0.0.1:10000`（端口取
  环境变量 `AQUARIUM_PORT`，默认 10000），每 0.6s 轮询 `/api/state`；后台未运行时
  自动执行 `python app.py` 拉起，退出时只关闭自己拉起的进程。
- **替换贴图**：把透明背景 PNG 放入 `desktop/assets/` 并重启程序，即可替换鱼、
  死鱼、鱼食、水草、气泡、渔网/喂食光标的外观；缺哪个文件就回退到内置绘制，
  详见 `desktop/assets/README.md`。
- 预览图：`desktop/preview_clear.png`（清澈）与 `desktop/preview_murky.png`（浑浊），
  可用 `python -m desktop.smoke_test` 重新生成。

## 看板内容

- **生态健康指数**：综合水质与理想范围的偏差，0~100。低于 60 建议先喂鱼，
  高于 90 建议先干活——缸再好看，KPI 也不会自己游起来。
- **种群统计**：🐠 鱼、🌿 水草、🦠 硝化细菌、🍤 剩余食物、🧹 有机废物。
- **水质指标**：溶解氧、氨氮、亚硝酸盐、硝酸盐、pH、温度，各带理想范围彩色量表。
- **历史趋势**：溶解氧 / 氨氮 / 硝酸盐随时间变化的折线图。
- **外部条件控制**：暂停/继续、喂食、开/关灯、加草、补菌、加鱼、重置，以及
  模拟速度、温度滑块。

## API 接口

基址即后台地址（默认 `http://127.0.0.1:10000`）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET  | `/api/state`  | 返回鱼缸当前完整状态 + 历史趋势 |
| POST | `/api/control` | 施加外部条件，body: `{"action": ..., "value": ...}` |
| GET  | `/api/health` | 健康检查 |

`/api/control` 支持的 `action`：

- `pause` / `resume`：暂停 / 继续模拟
- `speed`：设置速度倍速（0.1~10），`value` 数值
- `feed`：喂食，`value` 食物量（默认 1）
- `light`：开/关灯，`value` 布尔
- `temp`：设定温度（4~35°C），`value` 数值
- `add-plants`：加草数量，`value`（默认 1）
- `add-bacteria`：补菌量，`value`（默认 5）
- `add-fish`：加鱼数量，`value`（默认 1）
- `reset`：重置到初始状态

## 模拟模型简述

- 鱼代谢产生有机废物 → 氨氮；剩余食物腐烂也产生氨氮。
- 硝化细菌把氨氮转化为亚硝酸盐，再转化为硝酸盐（受温度、溶氧影响）。
- 水草在光照下吸收硝酸盐并产生溶解氧；鱼耗氧；温度越高水溶解氧越少。
- 鱼因氨氮过高、缺氧、亚硝酸盐过高而死亡，条件良好时繁殖。
- pH 缓慢向中性漂移并带噪声。
