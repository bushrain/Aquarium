# 贴图资源目录

把**透明背景 PNG** 按下面的文件名放进本目录，重启桌面鱼缸即可替换对应的默认绘制；
缺少的文件会自动回退到程序内置绘制，不影响运行。

| 文件名 | 用途 | 建议尺寸 | 说明 |
| --- | --- | --- | --- |
| `fish.png` | 所有鱼的基础贴图 | 128×64 | 朝右；会被程序淡染成 6 种鱼群配色，建议用浅色/白色素材 |
| `fish_0.png` ~ `fish_5.png` | 指定配色的鱼贴图 | 128×64 | 提供则随机选用且不再淡染，适合自带色彩的素材 |
| `corpse.png` | 死鱼贴图 | 128×64 | 默认已是翻白肚姿态，程序只加朝向翻转与轻微旋转 |
| `food.png` | 鱼食颗粒 | 16×16 | 按颗粒大小缩放（约 6~12px） |
| `plant.png` | 水草 | 64×128 | 底部为根；程序负责摇摆与高度缩放（约 55~190px 高） |
| `bubble.png` | 气泡 | 16×16 | 按气泡大小缩放（约 5~9px） |
| `net.png` | 渔网光标 | 48×48 | 热点取图像中心 |
| `feed_cursor.png` | 喂食光标 | 48×48 | 热点取图像中心 |

注意事项：

- 必须带 alpha 透明背景，否则会遮住水体。
- 鱼贴图统一**朝右**绘制，程序负责水平翻转。
- 替换后需重启程序（贴图在启动时缓存）。
